# CS-250-Software-Development-Lifecycle
This repository contains work from my CS 250 course and will be used as part of my computer science portfolio.


How do I interpret user needs and implement them into a program? How does creating user stories help with this?

I think that interpreting user needs starts with really understanding what the user is asking for and what they are trying to accomplish. User stories help because they break larger requirements into smaller pieces that are easier to understand and work on. They also help keep the focus on what the user actually needs instead of just what the developer thinks should be included. Acceptance criteria are also helpful because they give the team a clear way to know when the requirement has been completed correctly. One thing I learned in this course is that it is better to ask questions and get clarification instead of making assumptions.

How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?

When I approach developing a program, I like the idea of breaking the work into smaller sections instead of trying to do everything at once. Agile really supports that because the project can be worked on in shorter sprints and adjusted as new information comes up. In the future, I would like to use user stories, Sprint Planning, regular communication, testing throughout development, and retrospectives. I think that these processes can help keep a project organized while still giving the team room to make changes when needed.

What does it mean to be a good team member in software development?

For me, being a good team member in software development means communicating, being dependable, and being willing to work with others when problems come up. Everyone on a development team has a different responsibility, but those roles still depend on each other. I think that a good team member should be open to feedback, ask questions when something is unclear, and make sure other team members have the information they need. This course has really showed me that teamwork is really important in Agile because the whole team has to work toward the same goal for the project to be successful.
